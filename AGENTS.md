# Deutsch: Грамматика — инструкция для агентов

Единый источник правды по проекту: продукт (бывшее «ТЗ»), правила составления заданий (бывшая «Грамматика») и порядок работы. Банк заданий лежит отдельно в `data/tasks.json`.

Язык общения с пользователем и интерфейса — русский. Задания — на немецком.

## 1. Что это

Личное приложение для тренировки немецкой грамматики (A2–B2) на телефоне: тесты по грамматическим блокам, баллы, слабые места, работа над ошибками. Один пользователь, без входа.

- **Сейчас:** один HTML-файл, опубликованный как артефакт в Claude (с опциональным ИИ).
- **Цель:** Telegram Mini App без ИИ, только банк заданий (раздел 9).

## 2. Принятые решения

| Вопрос | Решение |
| --- | --- |
| Источник заданий | Готовый банк `data/tasks.json`. Режим по умолчанию «Без ИИ». В артефакте есть ещё «Банк + ИИ» и «Только ИИ»; в Telegram выбор скрыт, только банк |
| Пополнение банка | Только дописываем: новые задания по материалам курсов, плохие — удаляем по замечаниям. Весь банк не перегенерируем. Фиксированные блоки (сейчас M) не генерируются ИИ |
| Блоки | 13 блоков A–M (раздел 6). Новые блоки — только после согласования с пользователем. По умолчанию выбраны все |
| Сложность | Легко / Средне / Сложно = 5 / 10 / 15 заданий **на каждый выбранный блок** |
| Состав блока | Задания блока делятся по типам в пропорциях (`types` блока); пользователь меняет их в настройках |
| Баллы | Верно 1, почти 0,5, неверно 0 |
| Слабый блок | Доля баллов < 70% за последние 3 прохождения |
| Перевод | Только русский → немецкий |
| Кнопки ä ö ü ß | Опция в настройках, по умолчанию выключена |
| «Как это работает» (ⓘ) | Экран с описанием логики. **Обновлять при каждом изменении функционала или логики** |
| Не входит | Шеринг, вход, несколько пользователей |

## 3. Экраны

1. **Главная:** ⓘ и ⚙ сверху справа; большая кнопка «Старт», под ней строка «блоки · сложность · N заданий · режим» (нажатие → настройки); «Продолжить тест» (если есть незаконченный); «Работа над ошибками»; сводка «Где больше ошибок (последние 3 прохождения)», слабые красным.
2. **Настройки:** сложность; «Задания и проверка» (Без ИИ / Банк + ИИ / Только ИИ); «Показать результат в конце»; кнопки ä ö ü ß; список блоков (Все / Снять), у каждого уровень, пример и раскрывающийся состав типов (− / +, «Сбросить к стандарту»). Сохраняются.
3. **Как это работает:** описание логики (источники заданий, баллы, слабые блоки, работа над ошибками).
4. **Квиз:** одно задание на экране, «Блок X · название», тип, «Вопрос N из M», баллы, прогресс, «Отменить тест» с подтверждением. Незаконченный тест сохраняется.
5. **Ответ:** зелёный / жёлтый / красный, эталон, подсказка. Самооценка: свой ответ рядом с эталоном и кнопки «Верно / Почти / Неверно». Опция «Показать результат в конце» скрывает оценку до итога.
6. **Итог:** баллы всего и по блокам, разбор ошибок (всегда), кнопки «Работа над ошибками», «Пройти ещё раз», «На главную».

Интерфейс простой, под телефон, светлая и тёмная темы. Без `alert/confirm` — только встроенные подтверждения.

## 4. Типы заданий и проверка

| type | Название | Ввод | Проверка |
| --- | --- | --- | --- |
| `choice` | Выбор ответа | тап по варианту | совпадение с `answers` |
| `fill` | Вставить слово | поле ввода | список `answers` |
| `fix` | Исправить ошибку | исходное предложение в поле, правится целиком | список `answers` → иначе самооценка / ИИ |
| `translate` | Перевод RU → DE | поле ввода | список `answers` (1–5 вариантов) → иначе самооценка / ИИ |
| `build` | Составить предложение | тап по словам (чипы из `text`, разделитель ` / `), тап по слову в строке убирает его, «Сбросить» | список `answers` |
| `combine` | Объединить / преобразовать | поле ввода, инструкция в `prompt` | список `answers` → иначе самооценка / ИИ |

- Сравнение: нижний регистр, без знаков препинания, схлопнутые пробелы. **Блок K** (`strict`) — регистр и запятые учитываются.
- Без ИИ: свободный ответ без точного совпадения → самооценка.
- С ИИ («Банк + ИИ»): оценка Claude, быстрая модель. 1 — верно (в т. ч. другой правильный вариант), 0,5 — тема блока выполнена, ошибка мелкая или в выборе слова (например, ankommen вместо kommen), 0 — нарушена тема блока или другой смысл.

## 5. Формат данных

`data/tasks.json`:

```json
{
  "blocks": {
    "A": {
      "name": "Порядок слов, TeKaMoLo", "level": "A2–B1",
      "rule": "краткое правило для подсказок и для ИИ",
      "example": "пример предложения для списка блоков",
      "types": {"build": 4, "fix": 2, "translate": 4, "combine": 0},
      "ex": "образцы заданий с курсов (необязательно)",
      "fixed": false, "strict": false
    }
  },
  "tasks": [
    {"id": "A16", "block": "A", "type": "build", "prompt": "Составьте предложение.",
     "text": "am Montag / ich / habe / einen Brief / geschrieben",
     "answers": ["Am Montag habe ich einen Brief geschrieben."],
     "hint": "1–2 предложения по-русски, почему так",
     "options": ["только для choice, верный вариант внутри"],
     "note": "необязательно: часть речи, напр. «предлог (например: mit, zu, von)»"}
  ]
}
```

Правила данных:
- `id` = буква блока + номер. **Никогда не менять и не переиспользовать id**: на них ссылается прогресс. Новые задания получают следующий свободный номер.
- `choice` и `fill` — в `text` ровно один `___` (в `fill` допустимо `___ ___` для двух слов).
- `build` — слова из `text` (без учёта регистра и знаков) совпадают со словами каждого ответа.
- `fix` — `text` не совпадает ни с одним ответом.
- `types` блока — допустимые типы и стандартные пропорции; тип с 0 возможен, но по умолчанию не берётся.
- После правок банка — прогнать проверку (`scripts/validate.py`: формат, дубли, `choice`/`build`/`fix`).

## 6. Блоки

| Блок | Тема | Уровень | Типы по умолчанию (на 10) | Особенности |
| --- | --- | --- | --- | --- |
| A | Порядок слов, TeKaMoLo | A2–B1 | составить 4, исправить 2, перевод 4 | |
| B | Времена | A2–B1 | вставить 3, выбор 2, преобразовать 2, перевод 3 | haben/sein, Partizip II, Präteritum, Plusquamperfekt |
| C | Passiv и Konjunktiv II | B1–B2 | выбор 5, преобразовать 2, перевод 3 | |
| D | Падежи, предлоги, местоимения | A2–B1 | вставить 6, выбор 2, исправить 1, перевод 1 | Wo/Wohin, Dat перед Akk |
| E | Притяжательные местоимения | A2 | вставить 6, выбор 2, перевод 2 | euer → eure |
| F | sich + предлог | B1 | вставить 4, выбор 4, перевод 2 | sich Akk/Dat, da(r)-/wo(r)- |
| G | Прилагательные | A2–B1 | вставить 9, перевод 1 | после der / ein / без артикля |
| H | Relativsätze | B1–B2 | вставить 4, объединить 3, перевод 3 | dessen/deren, с предлогом |
| I | Союзы и связки | A2–B2 | составить 2, выбор 2,5, вставить 2,5, перевод 2, объединить 1 | weil/denn/deshalb, zu-обороты, двойные союзы |
| J | Темпоральные придаточные | B1 | выбор 4, вставить 1, перевод 2,5, объединить 1, исправить 1 | als/wenn, nachdem: время на шаг раньше |
| K | Правописание | A2–B2 | выбор 3, исправить 7 | `strict`: регистр и запятые важны |
| L | Смешанные переводы | B1–B2 | перевод 10 | несколько тем в одном предложении |
| M | Глаголы с предлогами | B1 | только выбор | `fixed`: список из учебника (с. 87–89), 64 с Akk + 96 с Dat, одно задание на пару «глагол + предлог» |

Nachdem (блок J): главное в Präsens/Futur I → придаточное в Perfekt; главное в Präteritum/Perfekt → придаточное в Plusquamperfekt.

## 7. Как составлять задания

- Уровень A2–B2, бытовая лексика, без редких слов. Подсказки по-русски, 1–2 предложения.
- Задания — **собственные примеры по правилу блока**. Тексты учебников не копировать; из материалов курсов берутся формат, сложность и темы.
- У каждого задания однозначный верный ответ. В `choice` дистракторы не должны быть тоже допустимыми (например, `helfen bei` — не давать `mit`; `schmecken nach` — не давать `wie`).
- `fix`: ровно одна ошибка — порядок слов, число или склонение (не опечатка). В K — заглавная буква, запятая, das/dass.
- `translate` и `combine`: перечислить 1–5 верных вариантов (порядок слов, синонимы, Perfekt/Präteritum).
- `note` — когда нужно вставить определённую часть речи: «предлог (например: mit, zu, von)», «возвратное местоимение (например: mich, uns, euch)», «относительное местоимение (например: die, dem, deren)».
- Около 100 заданий на блок; блок M — фиксированный список.

### Частые ошибки пользователя (учитывать при составлении)

- Порядок слов: подлежащее после союза (weil ich…); после je…desto — глагол сразу; weil и deshalb в одном предложении; Akk-местоимение перед Dat (ihn ihnen), два существительных — Dat перед Akk; nicht в конце.
- Времена: sein у глаголов смены состояния (aufstehen, bleiben, umziehen, fallen); fahren + прямое дополнение → haben; nachdem + Plusquamperfekt; als, а не wann; Plusquamperfekt только для более раннего действия; wird/werden по числу.
- Konjunktiv II: wäre без инфинитива, würde с инфинитивом; прошлое — hätte/wäre + Partizip II.
- Падежи: anrufen + Akk; Dativ при «кому», Dat. мн. ч. (mit den Kindern); sich Akk/Dat; предлог после глагола.
- zu-обороты: Lust haben + zu, zu у отделяемых приставок (zuzumachen), ohne/statt/um + zu.
- Перевод: внимательно читать русский текст (из-за дождя = wegen); орфография (Chef, schnell, solange).

## 8. Прогресс

- Хранится: по каждому блоку баллы последних 3 прохождений `{s, n}` и id заданий с невыправленными ошибками; счётчик показов каждого задания; настройки; незаконченный тест.
- После завершённого теста: верно решённое задание уходит из ошибок, новая ошибка добавляется.
- Выбор из банка: сначала задания, которые показывались реже всего, среди равных — случайно.
- «Работа над ошибками»: сначала ошибки из слабых блоков, затем добор из этих блоков; размер = сложность.

## 9. Telegram Mini App (следующий этап)

- Статический сайт: `index.html` + `data/tasks.json`, хостинг GitHub Pages (HTTPS). Сервер не нужен.
- Без ИИ: режим выбора скрыт, всегда банк + самооценка.
- Хранение: `Telegram.WebApp.CloudStorage` (лимиты: 1024 ключа, значение до 4096 символов — прогресс и счётчики показов разбивать по ключам, например по блокам), запасной вариант — `localStorage`.
- Тема из `themeParams`, системная кнопка «Назад» (`BackButton`), лёгкая вибрация (`HapticFeedback`), `ready()` и `expand()` при старте.
- Бот через @BotFather; ссылка на Pages задаётся как Mini App / кнопка меню.

## 10. Порядок работы

- Каждое изменение логики или интерфейса → обновить экран ⓘ и этот файл.
- Новые материалы курсов от пользователя → распределить по блокам, дописать задания, прогнать проверку, показать пользователю, что добавлено.
- Перед сменой формата данных или удалением блоков — согласовать.
- Коммиты небольшие, по одному изменению; описание на русском.
