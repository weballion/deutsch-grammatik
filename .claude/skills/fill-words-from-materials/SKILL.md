# Пополнить банк слов

Раздел «Слова» — тест на лексику: слово на языке интерфейса → выбрать немецкое из 4 (или наоборот).
Неверные варианты приложение берёт из этого же банка само (той же части речи), поэтому в банке
хранятся только сами слова. Правила — в `AGENTS.md`, раздел 5 «Банк слов». Нужна модель Opus
(переводы на два языка, части речи, артикли) — если сессия не на Opus, скажи об этом и предложи
переключиться или получи подтверждение.

## Шаг 1. Уровень и архив исходников

**Всегда спроси уровень** (A2–B2 или A1–A2), если пользователь не назвал его в этом запросе. Не угадывай.

Исходные фото скопируй в папку дня `materials/words/<уровень>/processed/ГГГГ-ММ-ДД/` (сегодняшняя дата),
имя файла — `<дата урока>_<короткое-описание>.jpg` (дата урока обычно написана на листе от руки; если её
нет — сегодняшняя). Там же ведётся `log.md` дня — несколько пополнений за день идут в ту же папку и тот же
журнал.

## Шаг 2. Выписать слова

Источник урока — `data/words/<уровень>/<дата урока>.json`:

```json
{"lesson": "2026-11-03", "title": "Lektion 1", "words": [
  {"id": "W1", "de": "die Agentur", "pos": "noun", "ru": "агентство", "uk": "агентство", "pl": "-en"},
  {"id": "W20", "de": "sich bemühen", "pos": "verb", "ru": "стараться (добиться)", "uk": "намагатися (домогтися)", "gov": "um + A."}
]}
```

- `pos`: `noun` / `verb` / `adj` / `other` (наречия, выражения). Существительное — всегда с артиклем
  (`der/die/das`), `pl` — как в учебнике (`-en`, `¨-e`, `Sg.`, `Pl.` или полная форма `die Praktika`).
- `gov` — управление/конструкция (`auf + A.`, `+ G.`, `sich einig sein`), в `de` его не пишем.
- `ru`/`uk` — короткий перевод, несколько значений через запятую, разные значения через `;`, уточнение в
  скобках. Приложение считает слова «одинаковыми по смыслу», если совпала хоть одна часть до/после
  запятой (без скобок) — такие не попадут в варианты вместе. Поэтому синонимы внутри банка пиши так,
  чтобы общая часть совпадала дословно (например, «уведомлять»), — тогда они не окажутся двумя
  «верными» вариантами.
- `ex` — обязательный пример `{"de": ..., "ru": ..., "uk": ...}`: одно короткое понятное предложение
  (A2–B1, бытовые ситуации: работа, жильё, учёба), где слово стоит в том значении, что в `ru`/`uk`,
  с управлением из `gov`, если оно есть. Свой пример, не из учебника. Переводы — естественные, не
  дословные. Пример показывается после ответа, поэтому он должен помогать запомнить слово.
- `id` — `W` + следующий свободный номер **по всему банку уровня** (смотри максимум во всех файлах папки).
  Никогда не меняй и не переиспользуй id — на них ссылается прогресс.
- Рукописные переводы пользователя сверяй: неточные исправляй, пустые — дописывай. Слова через «/»
  (annehmen/ablehnen) — отдельными записями. Слово, которое уже есть в банке уровня, второй раз не
  добавляй.
- Если урок с этой датой уже есть — дописывай слова в его файл.

## Шаг 3. Собрать и проверить

`uv run scripts/build.py` — собирает `data/words_<уровень>.json` и запускает `scripts/validate_words.py`
(id, обязательные поля, артикли, дубли). Доводи до «Ошибок нет».

## Шаг 4. Журнал и отчёт

В `log.md` дня: таблица (дата, файлы, урок, сколько слов, диапазон id) и под ней — какие переводы
исправлены, что объединено/разделено/пропущено. Пользователю — кратко: уровень, сколько слов из каких
уроков, диапазон id, что исправлено, проверка чистая. Коммит не делать — пользователь решает сам.
